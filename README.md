## <a name="цель-работы"></a> 🎯 1. Цель работы
Получить базовые практические навыки построения веб-интерфейсов без использования сторонних UI-библиотек (фреймворков). 
* Освоение семантической разметки **HTML5**.
* Изучение каскадных таблиц стилей **CSS3**.
* Применение современных подходов к позиционированию элементов (CSS Grid Layout / Flexbox) для построения сетки клавиш.

## <a name="стек-технологий"></a> 🛠 2. Стек технологий
* **HTML5**: Структура документа, формы, кнопки и поля ввода.
* **CSS3**: Стилизация, цвета, тени (box-shadow), скругления (border-radius) и типографика.
* **CSS Grid**: Использован для создания равномерной сетки кнопок калькулятора.
* **CSS Flexbox**: Использован для выравнивания калькулятора по центру экрана.
