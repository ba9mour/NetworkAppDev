## <a name="цель-работы"></a> 🎯 1. Цель работы
Получить навыки написания алгоритмов с использованием нативного JavaScript:
* Работа с циклами и условиями.
* Манипуляция массивами (включая методы высшего порядка, такие как `reduce`, `slice`).
* Работа с объектами (включая алгоритмы глубокого рекурсивного обхода свойств `Object.keys()`).
* Обработка краевых случаев и создание чистых (pure) функций без мутаций исходных данных.

## <a name="выполненные-задачи"></a> 📝 2. Выполненные задачи (Вариант)
В рамках домашнего задания реализованы следующие функции (согласно индивидуальному варианту):

* **Уровень 1 (Задание 1.3):** `sumOfSquares(arr)` — вычисление суммы квадратов всех элементов массива.
* **Уровень 1 (Задание 1.7):** `isEqualObj(obj1, obj2)` — глубокое сравнение двух объектов на идентичность их ключей и значений (с использованием рекурсии).
* **Уровень 2 (Задание 2.3):** `getMaxOnes(str)` — поиск максимальной последовательности подряд идущих единиц (`1`) в бинарной строке (линейный алгоритм).
* **Уровень 3 (Задание 3.2):** `inverse(arr, keep)` — разворот массива в обратном порядке с возможностью фиксации заданного количества элементов в начале или в конце (без мутации оригинального массива).

## <a name="стек-технологий"></a> 🛠 3. Стек технологий
* **Vanilla JavaScript (ES6+)**: Вся логика реализована исключительно на нативном языке без использования сторонних утилит (lodash и т.д.).
* **Node.js**: Среда выполнения для запуска и тестирования скриптов через терминал.
