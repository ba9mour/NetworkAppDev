## <a name="цель-работы"></a> 🎯 1. Цель работы
Получить практические навыки работы с 3D-графикой в браузере и нативными API для хранения данных:
* Изучение основ библиотеки **Three.js** (сцены, камеры, освещение, рендеринг).
* Асинхронная загрузка геометрии с помощью `GLTFLoader`.
* Работа с локальной базой данных браузера **IndexedDB** для хранения пользовательских файлов.
* Построение модульной архитектуры JavaScript (ES Modules).

## <a name="стек-технологий"></a> 🛠 2. Стек технологий
* **HTML5 & CSS3**: Семантическая разметка и адаптивная сетка (Grid Layout) без использования сторонних UI-фреймворков.
* **Vanilla JavaScript (ES6+)**: Модульная структура (`type="module"`).
* **Three.js**: Рендеринг 3D-сцен (подключен через `importmap` напрямую с CDN).
* **IndexedDB**: Локальное хранение загруженных `.glb` моделей (без использования бэкенда).
