# Лабораторная работа №2: Интерактивный калькулятор (JavaScript)

Учебный проект в рамках курса «Разработка сетевых приложений» (МГТУ им. Н.Э. Баумана, кафедра ИУ5). Проект представляет собой реализацию логики классического калькулятора с использованием нативного JavaScript (Vanilla JS).

## <a name="цель-работы"></a>  1. Цель работы
Получить практические навыки написания клиентской логики веб-приложений и взаимодействия с DOM-деревом.
* Изучение базовых концепций **JavaScript (ES6+)**.
* Работа с событиями (`Event Listeners`).
* Манипуляция элементами DOM (чтение ввода и вывод результата).
* Реализация алгоритма математических вычислений и обработки исключительных ситуаций.

## <a name="стек-технологий"></a>  2. Стек технологий
* **HTML5 & CSS3**: Разметка и стилизация (наследуется из ЛР1).
* **Vanilla JavaScript (ES6+)**: Вся бизнес-логика реализована без использования сторонних библиотек и фреймворков.
