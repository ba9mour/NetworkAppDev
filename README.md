# Разработка сетевых приложений (NetworkAppDev)

Учебный репозиторий студента кафедры ИУ5 (МГТУ им. Н.Э. Баумана) Багандова Мурада.

##  О курсе

Данный курс охватывает полный цикл создания современных веб-приложений (Frontend + Backend). Основной фокус направлен на изучение экосистемы JavaScript, переход от устаревших подходов (legacy) к промышленным стандартам разработки (Enterprise), а также работу с 3D-графикой в браузере.

##  Структура проекта

Репозиторий разбит на логические этапы (лабораторные и домашние работы), демонстрирующие эволюцию приложения:

* **ЛР 3–4: Базовый фундамент**
* Создание статической верстки и компонентов.
* Подъем базового REST API бэкенда на базе **Express (Node.js)** для отдачи мок-данных (`stocks.json`).


* **ЛР 5: Сетевое взаимодействие (Legacy)**
* Реализация клиент-серверного общения через классический объект `XMLHttpRequest`.
* Изучение событийной архитектуры (коллбэки).
* Столкновение с политикой Same-Origin Policy и обход проблемы CORS.


* **ЛР 6: Промышленные стандарты (Modern Web)**
* Рефакторинг сетевого слоя: полный переход на **Fetch API**, `Promises` и синтаксис `async/await`.
* Внедрение системы сборки **Vite**: настройка модульной архитектуры, Tree-shaking, минификация кода и управление зависимостями (NPM).
* Устранение проблемы CORS на уровне архитектуры: раздача собранного бандла (`public/`) напрямую с Express-бэкенда.


* **Домашнее задание 1: Алгоритмы и структуры данных**
* Глубокая работа с коллекциями, массивами и объектами в JavaScript.
* Реализация алгоритмов сортировки, фильтрации, глубокого сравнения объектов и рекурсии (в контексте предметной области "Конвейерные линии").


* **Домашнее задание 2: Интерактивная 3D-галерея**
* Интеграция библиотеки **Three.js** для работы с WebGL.
* Настройка сцены, освещения, камеры и `OrbitControls`.
* Работа с асинхронной базой данных браузера **IndexedDB** для загрузки и локального хранения пользовательских 3D-моделей в формате `.glb` (`GLTFLoader`).



##  Технологический стек

**Frontend:**

* Vanilla JavaScript (ES6+)
* HTML5 / CSS3 (Grid, Flexbox)
* Bootstrap 5
* Three.js (WebGL)

**Backend & Инфраструктура:**

* Node.js
* Express.js
* Vite (Bundler / Dev Server)
* NPM





**ЛР6

1. Скомпилируйте оптимизированный бандл фронтенда:
```bash
npm run build

```


2. Скопируйте содержимое папки `public` в корень бэкенд-сервера Express.
3. Запустите Node.js сервер:
```bash
npm start

```



Приложение будет доступно по адресу `http://localhost:3000`.
